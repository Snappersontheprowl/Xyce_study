# 脚本目录

## 功能

本目录用于保存服务于源码学习、文档维护、验证辅助的小型脚本。

脚本应保持可读、可复查，不承担大型构建系统或长期服务进程职责。

## 本级模块职责

- `README.md`：说明脚本目录职责和维护约定。

## 命名规则

- 脚本文件名使用英文小写和连字符或下划线，名称应直接表达用途。
- 不使用 `tmp`、`new`、`final`、`test2` 等阶段性命名。

## 当前约定

- 新增脚本时，在脚本头部或相邻文档中说明用途、输入和输出。
- 能用一条清晰命令完成的临时操作，不必沉淀为脚本。
- 会修改仓库内容的脚本应默认可审计，避免隐藏式批量重写。
