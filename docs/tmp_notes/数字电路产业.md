# 数字集成电路产业与芯片设计基础

## 一、数字集成电路产业链

数字集成电路产业可以概括为：

```text
半导体材料与设备
        ↓
芯片设计
        ↓
晶圆制造
        ↓
封装测试
        ↓
芯片成品
        ↓
电子系统
```

### 1. 半导体材料与设备

为芯片制造提供基础条件。

主要材料包括：

* 硅片
* 光刻胶
* 电子气体
* 化学试剂
* 靶材

主要设备包括：

* 光刻机
* 刻蚀机
* 薄膜沉积设备
* 离子注入设备
* 检测设备

材料、设备和工艺能力共同决定晶圆厂能够实现的制造节点，如 28 nm、14 nm、7 nm 等。

### 2. 晶圆工艺与 PDK

晶圆厂根据制造能力建立工艺平台，并向芯片设计公司提供 PDK。

PDK，即工艺设计套件，通常包括：

* 晶体管模型
* 设计规则
* 版图层定义
* 寄生参数提取规则
* 仿真模型

芯片设计必须按照目标晶圆厂的 PDK 进行，否则版图可能无法制造。

## 二、数字芯片设计流程

### 1. 架构与功能设计

首先确定芯片需要完成什么功能，例如 CPU、GPU、通信芯片或控制芯片。

主要工作包括：

* 划分功能模块
* 设计处理器、存储器、接口和总线结构
* 制定性能、功耗、面积和成本目标

### 2. RTL 前端设计

使用 Verilog 或 SystemVerilog 描述数字电路功能。

RTL 主要描述：

* 数据如何运算
* 模块之间如何通信
* 寄存器如何随时钟更新
* 控制逻辑如何运行

完成 RTL 后，还需要进行功能仿真、形式验证等，确保逻辑正确。

### 3. 逻辑综合

逻辑综合工具将 RTL 转换为门级网表。

综合后的电路由标准单元组成，例如：

* 反相器
* 与非门、或非门
* 多路选择器
* 触发器
* 缓冲器

综合工具会根据时序、功耗和面积要求，选择不同类型和驱动能力的标准单元。

### 4. 数字后端设计

数字后端负责把门级网表转换为实际物理版图。

主要步骤包括：

* 芯片规划
* 标准单元布局
* 时钟树综合
* 信号布线
* 电源网络设计
* 时序与功耗优化

最终得到可以交付制造的芯片版图。

### 5. 签核与流片

版图完成后，需要进行最终检查：

* DRC：检查是否违反制造规则
* LVS：检查版图与电路是否一致
* STA：检查时序是否满足要求
* 寄生参数提取与后仿真
* 功耗、压降和电迁移分析

全部通过后，将版图数据交给晶圆厂制造，这一过程称为流片。

---

## 三、晶圆制造与封装测试

### 1. 晶圆制造

晶圆厂根据版图制作光罩，并在硅片上反复进行：

* 薄膜沉积
* 涂胶和光刻
* 刻蚀
* 离子注入
* 化学机械抛光
* 金属互连制造

经过数百至上千道工序后，一片晶圆上会形成许多相同的芯片裸片。

### 2. 晶圆测试

使用探针台对晶圆上的每个裸片进行初步测试，主要用于：

* 筛除失效裸片
* 测量性能和功耗
* 对裸片进行等级分类

不合格裸片通常不会进入封装阶段。

### 3. 封装

将合格裸片切割下来，安装到封装基板或引线框架中，并完成电气连接和机械保护。

常见封装形式包括：

* QFN
* BGA
* FC-BGA
* 2.5D、3D 封装
* Chiplet 封装

封装主要承担供电、信号连接、散热和机械保护等功能。

### 4. 成品测试

封装后的芯片还需要进行：

* 功能测试
* 性能测试
* 功耗测试
* 高低温测试
* 可靠性测试

合格芯片会根据频率、功耗等指标进行分档，之后安装到 PCB 上，用于手机、计算机、汽车、服务器和工业控制设备。

# 四、标准单元、功能模块、IP 和 EDA

这四个概念属于不同层级：

```text
晶体管
  ↓
标准单元
  ↓
功能模块
  ↓
IP
  ↓
SoC / 整颗芯片
```

EDA 工具贯穿整个设计流程。

## 1. 标准单元

标准单元是数字芯片中最基本、可重复使用的物理电路单元，例如：

* INV：反相器
* NAND：与非门
* NOR：或非门
* MUX：多路选择器
* DFF：触发器
* BUF：缓冲器

一个标准单元不仅包含逻辑功能，还包括：

* 晶体管级原理图
* 物理版图
* 时延数据
* 功耗数据
* 面积数据
* 不同工艺、电压和温度下的特性

同一种逻辑功能通常有不同驱动能力，例如：

```text
INV_X1
INV_X2
INV_X4
INV_X8
```

驱动能力越强，通常面积和功耗也越大。

逻辑综合工具使用标准单元库，将 RTL 转换为门级网表；后端工具再将这些单元放置到芯片版图中。

## 2. 功能模块

功能模块是为了完成某项具体任务而组织起来的一组数字电路，例如：

* 加法器、乘法器、ALU
* 寄存器组、FIFO、Cache
* 状态机、仲裁器、译码器
* 总线、交叉开关、数据路由模块
* AXI、APB、UART、SPI 接口模块

功能模块通常通过 RTL 描述。

例如，一个计数器经过逻辑综合后，会被转换为：

```text
计数器 RTL
    ↓
触发器、加法器、多路选择器
    ↓
对应的标准单元
```

因此，功能模块描述的是“要完成什么功能”，标准单元则是实现该功能的底层物理电路。

## 3. IP

IP，即知识产权核，是经过完整设计、验证和封装，可以在不同芯片项目中重复使用的功能模块或功能系统。

常见 IP 包括：

* CPU、GPU
* USB、PCIe、以太网控制器
* DDR 控制器与 DDR PHY
* SRAM
* PLL
* SerDes
* ADC、DAC

一个 IP 内部通常包含多个功能模块。

例如：

```text
UART IP
├── 发送状态机
├── 接收状态机
├── 波特率发生器
├── 发送 FIFO
├── 接收 FIFO
├── 校验模块
└── 总线接口模块
```

### IP 的主要类型

#### 软 IP

以 RTL 代码形式提供，可以综合到不同工艺中，灵活性较高。

例如：

* CPU RTL
* 总线控制器 RTL
* 数字信号处理模块

#### 硬 IP

已经完成物理版图设计，通常只能用于指定工艺。

例如：

* SRAM
* PLL
* SerDes
* DDR PHY

#### 固核 IP

介于软 IP 和硬 IP 之间，通常已经完成综合或部分物理设计，但仍保留一定调整空间。

## 4. EDA

EDA，即电子设计自动化，是用于辅助芯片设计、验证和实现的一整套软件工具。

### 前端 EDA

主要用于：

* RTL 仿真
* 功能验证
* 形式验证
* 逻辑综合
* 静态时序分析

### 后端 EDA

主要用于：

* 芯片规划
* 标准单元布局
* 时钟树综合
* 自动布线
* 时序优化
* 电源完整性分析

### 签核 EDA

主要用于：

* DRC
* LVS
* 寄生参数提取
* 时序签核
* 功耗与压降分析
* 电迁移分析

## 五、四者之间的关系

可以用盖房子进行类比：

* 标准单元：砖、门、窗等基础构件
* 功能模块：墙体、楼梯、房间等局部结构
* IP：完整的厨房、电梯或供水系统
* EDA：建筑设计、仿真和施工软件
* SoC：最终完成的整栋建筑

实际设计过程可以概括为：

```text
晶圆厂提供工艺与 PDK
        ↓
建立标准单元库和硬 IP
        ↓
设计人员编写 RTL 和功能模块
        ↓
多个功能模块构成 IP
        ↓
多个 IP 集成为 SoC
        ↓
使用 EDA 完成综合、布局布线和签核
        ↓
生成最终版图并流片
```

需要注意的是，功能模块与 IP 之间没有绝对的规模界限。

一个简单 FIFO 可以只是某个芯片内部的功能模块；如果它具有完整接口、充分验证、完善文档，并能够在多个项目中复用，也可以被封装为 FIFO IP。

## 六、核心总结

数字芯片设计的本质是：

```text
功能需求
  ↓
架构设计
  ↓
RTL 描述
  ↓
逻辑综合
  ↓
标准单元门级网表
  ↓
布局布线与签核
  ↓
物理版图
  ↓
晶圆制造
  ↓
封装测试
  ↓
芯片成品
```

其中：

* **标准单元**是实现数字逻辑的底层电路积木。
* **功能模块**是由标准单元实现的具体逻辑功能。
* **IP**是经过完整设计和验证、能够重复使用的功能系统。
* **EDA**是完成设计、验证、物理实现和签核的软件工具。
* **PDK**是连接芯片设计与晶圆制造的工艺基础。
