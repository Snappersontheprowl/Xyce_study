数字集成电路产业可以按下面这条链路理解：

**半导体材料与设备 → 芯片设计 → 晶圆制造 → 封装测试 → 芯片成品 → 电子系统**

### 1. 半导体材料与设备

为芯片制造提供基础条件，包括：

* 硅片、光刻胶、电子气体、化学试剂、靶材等材料
* 光刻机、刻蚀机、薄膜沉积设备、离子注入设备、检测设备等

这些环节决定了芯片能够采用什么工艺制造，例如 28 nm、14 nm、7 nm 等。

### 2. 晶圆工艺与 PDK

晶圆厂根据自身制造能力建立工艺平台，并提供 **PDK（Process Design Kit，工艺设计套件）**。

PDK 中包含：

* 晶体管模型
* 设计规则
* 标准层定义
* 寄生参数提取规则
* 仿真模型

芯片设计公司必须依据晶圆厂的 PDK 进行设计。

### 3. 芯片架构与功能设计

首先确定芯片“要做什么”，例如设计 CPU、GPU、通信芯片或控制芯片。

主要工作包括：

* 划分芯片功能模块
* 确定处理器、存储器、接口和总线结构
* 制定性能、功耗、面积和成本目标

### 4. RTL 前端设计

使用 Verilog、SystemVerilog 等硬件描述语言编写数字电路功能。

这一阶段主要描述：

* 数据如何运算
* 各模块如何通信
* 时钟到来时寄存器如何更新

同时需要进行功能仿真和验证，确保逻辑行为正确。

### 5. 逻辑综合

综合工具把 RTL 代码转换为由标准单元组成的门级电路，例如：

* 与门、或门、反相器
* 触发器
* 多路选择器
* 加法器

综合时会根据时序、功耗和面积要求选择合适的标准单元。

### 6. 数字后端设计

将门级电路真正放置到芯片版图中，主要包括：

* 芯片规划
* 标准单元布局
* 时钟树综合
* 信号布线
* 电源网络设计
* 时序优化

最终得到芯片的物理版图。

### 7. 签核与流片

版图完成后需要进行检查，包括：

* DRC：是否违反制造规则
* LVS：版图与电路是否一致
* STA：时序是否满足要求
* 功耗、压降、电迁移分析
* 寄生参数提取与后仿真

全部通过后，将版图数据交给晶圆厂，这一步称为**流片**。

### 8. 光罩制造与晶圆生产

晶圆厂根据版图制作光罩，并在硅片上反复进行：

* 薄膜沉积
* 涂胶和光刻
* 刻蚀
* 离子注入
* 化学机械抛光
* 金属互连制造

经过数百至上千道工序后，一整片晶圆上会形成许多相同的芯片裸片。

### 9. 晶圆测试

晶圆制造完成后，使用探针台对每个裸片进行初步测试。

主要目的是：

* 找出失效芯片
* 测量性能和功耗
* 对芯片进行等级分类

不合格的裸片通常不会进入封装阶段。

### 10. 封装

将合格裸片切割下来，安装到封装基板或引线框架中，并完成电气连接和保护。

常见封装包括：

* QFN
* BGA
* FC-BGA
* 2.5D、3D 封装
* Chiplet 封装

封装负责供电、信号连接、散热和机械保护。

### 11. 成品测试

封装后的芯片还要进行最终测试，包括：

* 功能测试
* 性能测试
* 功耗测试
* 高低温测试
* 可靠性测试

合格芯片会根据频率、功耗等指标进行分档。

### 12. 芯片成品与系统应用

测试合格后，芯片成为可以销售的成品，被安装到 PCB 上，最终用于：

* 手机和计算机
* 汽车电子
* 通信设备
* 服务器
* 工业控制设备

简单来说，**芯片设计负责把功能变成版图，晶圆厂负责把版图制造成裸片，封装测试厂负责把裸片变成可以使用的芯片成品。**



在数字芯片设计中，可以把 **标准单元、IP 和 EDA** 理解为三类不同的东西：

* **标准单元**：最基础的“电路积木”
* **IP**：已经设计好的“功能模块”
* **EDA**：完成芯片设计所使用的“软件工具”

它们共同服务于芯片设计。

## 1. 标准单元是什么

标准单元是数字芯片中最基本的物理电路单元，例如：

* 反相器 INV
* 与非门 NAND
* 或非门 NOR
* 多路选择器 MUX
* 触发器 DFF
* 缓冲器 BUF

虽然逻辑上只是一个门，但标准单元并不只是 Verilog 中的一条逻辑语句，而是一整套经过设计和验证的数据。

一个标准单元通常包含：

* 晶体管级原理图
* 物理版图
* 逻辑功能
* 输入输出延迟
* 功耗数据
* 面积数据
* 不同工艺、电压、温度下的特性

这些标准单元被整理成一个 **标准单元库**。

例如，同一个反相器可能有：

* INV_X1
* INV_X2
* INV_X4
* INV_X8

它们逻辑功能相同，但驱动能力、面积和功耗不同。

逻辑综合工具会使用标准单元库，把 RTL 代码转换成由这些标准单元组成的门级网表。后端工具再把这些单元摆放到芯片版图中。

## 2. IP 是什么

IP 是 **Intellectual Property Core，知识产权核**，可以理解为已经设计完成、可以重复使用的功能模块。

常见 IP 包括：

* CPU 核
* GPU 核
* USB 控制器
* PCIe 控制器
* DDR 控制器
* 以太网模块
* 图像处理模块
* SRAM
* PLL
* ADC、DAC

IP 的规模通常比标准单元大得多。

例如：

* 一个标准单元可能只是一个与非门
* 一个 USB IP 可能由几十万甚至更多标准单元组成

IP 可以分为三类。

### 软 IP

以 RTL 代码形式提供，例如 Verilog 或 SystemVerilog。

优点是可以综合到不同工艺中，灵活性较高。

例如：

* CPU RTL
* 总线控制器 RTL
* 数字信号处理模块 RTL

### 硬 IP

已经完成物理版图设计，通常只能用于指定工艺。

例如：

* SRAM
* PLL
* 高速 SerDes
* DDR PHY

硬 IP 通常直接以版图模块的形式放入芯片。

### 固核 IP

介于软 IP 和硬 IP 之间，可能已经完成综合和部分物理设计，但还保留一定调整空间。

## 3. IP 设计做什么

IP 设计不是简单地写一段代码，而是要把一个功能模块完整做出来。

以数字 IP 为例，主要包括：

1. 确定功能和接口
2. 编写 RTL
3. 进行功能验证
4. 进行逻辑综合
5. 检查时序、面积和功耗
6. 编写使用说明和验证环境
7. 将 IP 交付给芯片集成团队

IP 设计团队关注的是某个模块是否：

* 功能正确
* 接口规范
* 性能达标
* 能够重复使用
* 容易集成到其他芯片中

而整颗芯片的设计团队会把多个 IP 集成在一起。

例如一颗 SoC 可能包含：

* CPU IP
* GPU IP
* DDR IP
* USB IP
* PCIe IP
* SRAM
* 自研加速器 IP

然后通过总线和片上互连连接起来。

## 4. EDA 是什么

EDA 是 **Electronic Design Automation，电子设计自动化**。

它不是某一个软件，而是一整套用于芯片设计的软件工具。

由于现代芯片可能包含数十亿个晶体管，不可能完全依靠人工设计，因此必须依赖 EDA。

EDA 工具主要分布在整个芯片设计流程中。

### 前端 EDA

主要处理逻辑和功能，包括：

* RTL 编写辅助
* 功能仿真
* 形式验证
* 逻辑综合
* 静态时序分析

例如检查：

* RTL 功能是否正确
* 是否存在逻辑错误
* RTL 能否转换成门级电路
* 电路频率能否达到要求

### 后端 EDA

主要处理物理版图，包括：

* 芯片规划
* 标准单元布局
* 时钟树综合
* 自动布线
* 时序优化
* 功耗分析
* 电源完整性分析

后端 EDA 会把门级网表真正变成芯片版图。

### 签核 EDA

用于最终确认芯片是否可以流片，包括：

* DRC
* LVS
* 寄生参数提取
* 静态时序签核
* 功耗和压降分析
* 电迁移分析

## 5. 三者之间是什么关系

可以用“盖房子”来类比：

* **标准单元**：砖、门、窗等基础构件
* **IP**：已经设计好的厨房、卫生间、电梯系统
* **EDA**：建筑设计和施工软件
* **芯片设计人员**：使用这些工具和模块完成整栋建筑

实际设计流程大致是：

```text
工艺厂提供工艺和 PDK
        ↓
标准单元公司设计标准单元库
        ↓
IP 公司使用 RTL、标准单元或定制电路设计 IP
        ↓
芯片公司选择和自研多个 IP
        ↓
使用 EDA 进行验证、综合、布局布线和签核
        ↓
形成最终芯片版图
```

更具体一点：

```text
RTL 代码
   ↓
EDA 逻辑综合
   ↓
标准单元组成的门级网表
   ↓
集成 SRAM、PLL、CPU 等 IP
   ↓
EDA 布局布线
   ↓
芯片版图
```

## 6. 最容易混淆的一点

标准单元和 IP 并不是同一层级。

**标准单元是实现数字逻辑的底层组件，IP 是实现具体功能的较大模块。**

例如一个 CPU IP 内部可能包括：

* 加法器
* 寄存器
* 译码器
* 缓存控制逻辑

这些逻辑最终大部分都会被综合成大量标准单元。

但 SRAM、PLL、SerDes 等 IP 往往不是普通标准单元自动拼出来的，而是专门定制设计的硬 IP。

所以从设计层级看，可以理解为：

```text
晶体管
  ↓
标准单元
  ↓
功能模块
  ↓
IP
  ↓
SoC / 整颗芯片
```

**EDA 工具贯穿以上几乎所有层级，用来帮助设计、验证和实现。**









## 功能模块是什么

**功能模块**是为了完成某项具体逻辑功能而组织起来的一组数字电路。

它的层级通常位于标准单元和大型 IP 之间：

```text
晶体管
  ↓
标准单元
  ↓
功能模块
  ↓
IP
  ↓
SoC / 整颗芯片
```

例如，一个 32 位加法器就是一个功能模块。它内部可能由多个异或门、与门、或门等标准单元组成。

## 常见功能模块

数字芯片中的功能模块大致有以下几类。

### 1. 运算模块

负责数据计算，例如：

* 加法器
* 乘法器
* 除法器
* 比较器
* 移位器
* ALU（算术逻辑单元）

例如 ALU 可以根据控制信号完成加法、减法、与、或、比较等操作。

### 2. 存储模块

负责暂时保存数据，例如：

* 寄存器
* 寄存器组
* FIFO
* Cache
* SRAM
* 缓冲区

其中，普通寄存器通常由触发器标准单元组成；较大的 SRAM 一般作为专门的存储器 IP 使用。

### 3. 控制模块

负责控制电路按照一定顺序工作，例如：

* 状态机 FSM
* 指令译码器
* 中断控制器
* 仲裁器
* 流程控制器

例如，一个通信模块可能按照“等待数据—接收数据—校验数据—输出数据”的状态顺序运行，这通常由状态机控制。

### 4. 数据通路模块

负责数据在芯片内部的传输和选择，例如：

* 多路选择器
* 总线
* 交叉开关
* 数据路由模块
* 串并转换模块

它们决定数据从哪里来、经过什么处理、最后送到哪里。

### 5. 接口模块

负责不同模块之间的信息交换，例如：

* AXI 接口
* APB 接口
* UART 接口
* SPI 接口
* I²C 接口
* GPIO 控制模块

接口模块通常要规定数据格式、握手方式和传输时序。

## 功能模块是怎么设计出来的

设计人员通常使用 Verilog 或 SystemVerilog 描述功能模块。

例如一个简单计数器：

```verilog
always @(posedge clk) begin
    if (reset)
        count <= 0;
    else if (enable)
        count <= count + 1;
end
```

这段 RTL 描述的是一个计数功能模块。经过 EDA 综合以后，它会被转换成：

* 触发器
* 加法器
* 多路选择器
* 逻辑门

这些底层电路最终由标准单元实现。

```text
RTL 功能描述
      ↓
EDA 逻辑综合
      ↓
门级网表
      ↓
大量标准单元
```

## 功能模块和 IP 的区别

两者没有绝对严格的规模边界，主要区别在于**完整性和可复用性**。

### 功能模块

通常是芯片内部的一个组成部分，例如：

* 一个加法器
* 一个状态机
* 一个 FIFO
* 一个寄存器组

它可能只服务于当前芯片或当前项目。

### IP

通常是经过完整设计、验证和封装，可以提供给其他项目重复使用的功能系统，例如：

* UART IP
* USB IP
* DDR 控制器 IP
* CPU IP
* PCIe IP

一个 IP 内部通常包含很多功能模块。

例如 UART IP 内部可能包括：

```text
UART IP
├── 发送控制状态机
├── 接收控制状态机
├── 波特率发生器
├── 发送 FIFO
├── 接收 FIFO
├── 校验模块
└── 总线接口模块
```

因此可以简单理解为：

> **标准单元组成基础电路，多个基础电路组成简单功能模块，多个功能模块共同组成一个完整 IP。**

但这个层级并不绝对：一个设计成熟、接口完整、经过充分验证的 FIFO 模块，也可以作为 FIFO IP 对外提供。
